# Pilot onboarding checklist

Aim: a new pilot team is set up in under 30 minutes.

1. **Workspace (5 min).** Create the workspace and add the first admin (a staff member who can sign in).
2. **Demo project (2 min).** In the Supabase SQL editor run `select public.seed_demo_project('<workspace id>', '<admin user id>');`. This adds an example plan and three example emails the team can click through; archive the project when the pilot starts for real.
3. **People (5 min).** Add staff to the workspace; add outside partners as contributors. Give each project a project manager.
4. **Real project (5 min).** Create the project, then phases and the first tasks with owners and dates.
5. **Project email address (5 min).** Note the project's address (`<slug>@` the inbound domain) and CC it on one real email. Check it appears on the timeline within a minute.
6. **Tell the team (5 min).** Explain the rules: the app reads only messages sent to the project address, there are no per-person statistics, and every AI suggestion needs a person's click.
7. **First week.** Review the audit log (project manager) and collect feedback.
